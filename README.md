# COVID-19 & Hospital Capacity Analytics 🏥

**DOSM Datathon 2025 | Team: Data Phantoms**

## Project Overview
This project analyzes COVID-19 cases and hospital bed utilization in Malaysia using data analytics and interactive visualizations. It aims to identify hospital capacity challenges, monitor healthcare demand, and support data-driven resource planning.

## Objectives
- Analyze COVID-19 trends and hospital bed occupancy across Malaysia.
- Identify relationships between infection rates and hospital admissions.
- Explore hospital capacity and resource utilization.
- Develop an interactive dashboard to support healthcare planning.

## Tools & Technologies
- **Data Visualization:** Power BI
- **Data Analytics:** Exploratory Data Analysis (EDA), Statistical Analysis
- **Predictive Analytics:** Time-Series Forecasting (ARIMA/LSTM)
- **Data Sources:** Malaysian COVID-19 cases and hospital utilization datasets

## Methodology
1. Data collection and preprocessing
2. Data integration and cleaning
3. Exploratory data analysis
4. Statistical and predictive analysis
5. Interactive dashboard development

## Key Findings
- Identified differences in hospital bed utilization across Malaysian states.
- Observed a 7–14 day lag between increases in COVID-19 cases and hospital admissions.
- Developed an interactive Power BI dashboard to visualize infection trends and hospital capacity.
